## ✅ What Changed from v1.1.0

### Bug Fix 1: Radius Input Sync (CRITICAL)

**Problem:**
- HTML showed 200m, JavaScript used 300m
- Maps had only 22.4% of expected geometry
- Users got smaller maps than intended

**Fix:** templates/index.html line 494
```html
<!-- Before -->
<input type="number" id="radius" value="200" ...>

<!-- After -->
<input type="number" id="radius" value="300" ...>
```

**Impact:**
- Total triangles: 11,565 → 23,775 (2.1x increase!)
- vs Map2Model: 22.4% → 46.0% (2x improvement!)

### Bug Fix 2: Preview Circle Accuracy

**Problem:**
- Preview showed 300m circle
- Features actually clipped to 272m
- 9% discrepancy misleading users

**Fix:** templates/index.html lines 650-782
- Added dual-circle system (inner=features, outer=query)
- Tooltip explains feature boundary
- Calculates actual radius using backend logic

**Impact:**
- Preview now matches reality
- Educational UX improvement

### UX Improvement: PNC Park Default

**Change:**
- Default location: PNC Park (40.4469, -80.0056)
- Consistent test location for quality comparison
- Updated marker popup
