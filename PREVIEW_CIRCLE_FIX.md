# Preview Circle Accuracy Fix

**Date:** 2026-01-10
**Issue:** Preview circle on interactive map didn't match actual generated model area
**Status:** ✅ FIXED

---

## Problem

The interactive map preview showed a circle with the **query radius** (300m), but the actual 3D model features were **clipped to smaller radii** to accommodate the 5mm border ring.

### Discrepancy Example (300m radius)

- **Preview circle showed**: 300m radius
- **Water/roads actually extended to**: 280m radius (93% of preview)
- **Parks/buildings actually extended to**: 272m radius (91% of preview)

This created a misleading preview where the user expected features ~9% further out than they actually appeared in the generated model.

---

## Root Cause

The backend (app.py lines 1844-1857) clips features to make room for the border ring:

```python
border_width_mm = 5.0  # mm
feature_gap_mm = 2.0  # mm - gap for parks/buildings

# Water boundary: clips to inner edge of border ring (70mm)
water_radius_reduction_meters = border_width_mm / scale_factor
water_radius_meters = radius_meters - water_radius_reduction_meters

# Feature boundary: clips with 2mm gap before border ring (68mm)
feature_radius_reduction_meters = (border_width_mm + feature_gap_mm) / scale_factor
feature_radius_meters = radius_meters - feature_radius_reduction_meters
```

The frontend was showing the full `radius_meters` without accounting for these clipping reductions.

---

## Solution

Updated `templates/index.html` to:

1. **Calculate actual feature radius** using same logic as backend
2. **Show TWO circles**:
   - **Inner circle (solid, prominent)**: Shows actual feature boundary where parks/buildings extend (272m for 300m query)
   - **Outer circle (dashed, faded)**: Shows query area for reference (300m)
3. **Add tooltip** explaining the feature boundary radius

### Code Changes

**Added feature radius calculation** (matching backend):
```javascript
function calculateFeatureRadius(queryRadius) {
    const BASE_SIZE_MM = 150;
    const BORDER_WIDTH_MM = 5.0;
    const FEATURE_GAP_MM = 2.0;

    // Calculate scale factor (same as backend: app.py line 1829)
    const maxExtent = queryRadius * 2;
    const scaleFactor = BASE_SIZE_MM / maxExtent;

    // Parks/buildings are clipped with 7mm gap (5mm border + 2mm feature gap)
    const featureRadiusReductionMeters = (BORDER_WIDTH_MM + FEATURE_GAP_MM) / scaleFactor;
    const featureRadius = queryRadius - featureRadiusReductionMeters;

    return featureRadius;
}
```

**Updated circle rendering**:
- Main circle: Shows `calculateFeatureRadius(queryRadius)` with tooltip
- Outer circle: Shows `queryRadius` as dashed reference line
